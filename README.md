# المنصة القضائية الذكية — Egyptian Judicial Smart V2.1

منصة سيادية للذكاء القضائي والبحث القانوني وتنظيم الأدلة ودعم التسبيب — تجربة قضائية مقيّدة.

## المبدأ الأساسي

> **الذكاء الاصطناعي يُساعد العمل القضائي. القاضي يُمارس السلطة القضائية.**

## الميزات الرئيسية

### مساحة القضية (5 تبويبات منظّمة)
1. **نظرة عامة** — أطراف النزاع + ملخّص سريع + الخط الزمني + المواعيد القانونية
2. **الوقائع والأدلة** — الوقائع (محرّك الحالة) + الأدلة + المستندات (رفع + استخراج آلي)
3. **القانون** — السلطات المؤيِّدة/المخالفة + فحص رقم القانون + بوابة التحقق
4. **التحليل** — الرؤى والتعارضات + تحليل AI + المراجعة الخصومية (الظل القضائي)
5. **القرار** — حقول القاضي المستقلة + الملاحظات + مؤشرات السلامة

### مركز البحث القانوني
- 14 بوابة حكومية مصرية رسمية مسجّلة (الدستور، الجريدة الرسمية، النقض، مجلس الدولة، الدستورية العليا)
- 39 نصاً قانونياً موثَّقاً (دستورية + تشريعية) مع provenance كامل
- لقطة موقّعة رقميًا (EJB-CORPUS-2026.08-R1)
- بحث هجين (دقيق + معجمي + زمني)
- طابور استيراد للمصادر المؤسسية

### فصل صارم بين النظام والقاضي
- **system_proposal** — اقتراحات النظام (غير مُلزِمة)
- **judge_decision** — قرارات القاضي (مُلزِمة)
- **adversary_transfer** — نقل من المراجعة الخصومية
- سجل تدقيق غير قابل للتعديل

### بوابة Sphinx للنماذج
- توجيه سيادي للنماذج الخارجية (Groq / Gemini / HuggingFace)
- سياسة صارمة: القضايا الحرجة → النموذج السيادي المحلي
- تدهور آمن عند فشل المزوّدين
- كل مخرج يحمل وسم «غير مُلزِم»

### محرّك المواعيد القانونية المصرية
- 12 موعداً قانونياً (مرافعات، إجراءات جنائية، مدني، مجلس الدولة)
- حاسبة تلقائية مع مراعاة أيام الجمعة + الخصم خارج مصر

### رفع المستندات + الاستخراج الآلي
- القاضي يرفع المستندات بنفسه
- النظام يستخرج الوقائع والخط الزمني والاستشهادات آليًا
- كل استخراج «مرشّح» حتى يُعتمده القاضي
- ترقية العناصر المختارة إلى بيانات القضية

### واجهة 2026 متطورة
- Bento layouts + Glassmorphism + Micro-interactions
- Command Palette (Cmd+K) للبحث الشامل
- اختصارات لوحة المفاتيح (G+H/R/A/S)
- متجاوبة بالكامل مع الموبايل (قائمة سفلية)
- وضع مؤسسي فاتح

## التقنيات

- **Frontend**: Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui
- **Backend**: Next.js API Routes + Prisma ORM (SQLite)
- **State**: TanStack Query + Zustand
- **AI**: z-ai-web-dev-sdk (بوابة Sphinx)
- **Validation**: Zod schemas (typed API client)

## البدء

```bash
# 1. تثبيت الاعتماديات
bun install

# 2. إعداد قاعدة البيانات
bun run db:push

# 3. تشغيل الخادم
bun run dev

# 4. فتح المتصفح
# http://localhost:3000
```

## متغيرات البيئة (.env)

## الأمان
